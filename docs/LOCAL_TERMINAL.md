# Local terminal

The integrated successor to the initial Weston experiment is documented in
[TERMINAL_REPORT.md](TERMINAL_REPORT.md) and
[TERMINAL_INSTALL.md](TERMINAL_INSTALL.md).

It uses Sway, foot, wvkbd and the pinned CSOT touchscreen firmware. Follow the
exact run's validation report. A boot-only replacement does not install its
userspace or firmware; the full image overwrites userdata. Preserve the working
headless pair first. Physical display, touch and second-phone USB are unverified.
